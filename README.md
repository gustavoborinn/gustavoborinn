## Projetos que representam meu perfil

### Pipeline distribuído de processamento de vídeo

**Java, Spring Boot, RabbitMQ, PostgreSQL, MinIO, Docker, FFmpeg, Whisper, Swagger/OpenAPI**

Projeto acadêmico em equipe para processamento assíncrono de mídia. A aplicação recebe upload de vídeo e dispara tarefas paralelas para transcodificação, extração de áudio e geração de legendas.

- Arquitetura com API Gateway e workers independentes.
- Comunicação assíncrona com RabbitMQ e Fanout Exchange.
- Persistência de vídeos, tasks e status em PostgreSQL.
- Armazenamento de arquivos e artefatos em MinIO.
- Ambiente local reproduzível com Docker Compose.

### Extensão offline-first para SketchUp

**Ruby, SketchUp Ruby API, HTML, CSS, JavaScript, Node.js, Bash, PowerShell, Minitest**

Extensão comercial para automação de fluxos técnicos de arquitetura e interiores, estruturada como MVP distribuível em formato `.rbz`.

- Interface embarcada com `UI::HtmlDialog`.
- Arquitetura modular para evolução incremental.
- Scripts de empacotamento e validação estrutural.
- Testes básicos para lógica e build da extensão.
- Planejamento de distribuição via GitHub Releases.

### Aplicação mobile multi-módulo

**React Native, Expo, Firebase, Firestore, Cloud Functions, Firebase Storage, FCM, Zustand, React Query**

Projeto autoral de aplicação mobile com sete verticais funcionais integradas em uma única base de código.

- Separação por módulos funcionais.
- Autenticação, autorização e regras de acesso.
- Feature flags para controlar liberação de funcionalidades.
- Firebase como base para auth, dados, storage, cloud functions e notificações.
- Organização de estado e dados assíncronos com Zustand e React Query.

### Prescribe Guard

**JavaScript, SQLite WASM, D3.js, Web Workers, Python**

Projeto voltado à análise de interações medicamentosas com foco em funcionamento local e experiência interativa.

- Processamento local de dados com SQLite WASM.
- Uso de Web Workers para manter a interface responsiva.
- Visualização de dados com D3.js.
- Aplicação de tecnologia em um problema sensível da área da saúde.
